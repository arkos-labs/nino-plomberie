# Guide Setup — Google Local Services Ads (LSA)

## 📍 Qu'est-ce que LSA?

**Google Local Services Ads** = Les encadrés jaunes "Google Guaranteed" en haut des résultats Google

```
[Google Guaranteed] Nino Plomberie ⭐ 4.4
Plombier à Muret — 24h/24
Appeler
```

**Avantages:**
- ✅ Position TOP (au-dessus des annonces Google Ads)
- ✅ Paiement au lead (pas au clic)
- ✅ "Google Guaranteed" badge = confiance
- ✅ Affichage automatique 24/7

**Coût:** €0.50-2.00 par appel (dépend service)

**Objectif:** +15-30 appels/mois

---

## 🚀 SETUP COMPLET (30-45 minutes)

### ÉTAPE 1: Vérifier Google Business Profile
**Temps: 5 min**

```
1. Aller sur: google.com/business
2. Connectez-vous avec compte Google
3. Vérifier que "Nino Plomberie" apparaît
4. Vérifier les informations:
   - ✅ Nom: "Nino Plomberie"
   - ✅ Adresse: "11 Rue François Arago, 31600 Muret"
   - ✅ Téléphone: "06 50 57 96 20"
   - ✅ Catégorie: "Plombier"
   - ✅ Hours: "Ouvert 24 heures"
```

**Important:** Vérifier que le profil est COMPLÈTEMENT rempli (photos, description, services)

---

### ÉTAPE 2: Ajouter Services à Google Business

**Temps: 10 min**

```
1. Google Business > Menu > "Services"
2. Ajouter les services proposés:
   ✅ Fuite d'eau
   ✅ Débouchage
   ✅ Chauffe-eau & Cumulus
   ✅ Chauffage & Chaudière
   ✅ Robinetterie & Sanitaires
   ✅ Rénovation salle de bain
   ✅ Plomberie neuve
3. Pour chaque service:
   - Ajouter description courte (50-100 mots)
   - Upload photo(s) de réalisations
   - Définir zone intervention
4. SAUVEGARDER
```

**Description exemple (Fuite d'eau):**
```
Réparation fuite d'eau 24h/24 à Muret et Toulouse.
Recherche et diagnostic gratuit.
Intervention rapide: 15-30 min à Muret, 45 min-1h30 à Toulouse.
Garantie 2 ans pièces et main-d'œuvre.
```

---

### ÉTAPE 3: Accéder à Google Local Services Ads

**Temps: 5 min**

```
1. Google Business > Menu > "Services" > "Local Services Ads"
   OU
   Aller directement: google.com/ads/local-services
2. Vérifier message: "Complétez votre profil pour activer LSA"
3. Cliquer "Activer Local Services Ads"
```

---

### ÉTAPE 4: Configurer Profil d'identité Google

**Temps: 10-15 min**

**Trois étapes requises:**

#### A) Vérifier identité (ID + adresse)
```
1. Vous recevrez un code verification
2. Vérifier par SMS ou numéro téléphone
3. Prouver location (scan passeport/carte ID)
```

#### B) Vérifier numéro téléphone
```
1. Entrer numéro: 06 50 57 96 20
2. Google appelle (1 sec)
3. Vous répondez "OK"
```

#### C) Créer "Service Area"
```
1. Définir zones d'intervention:
   ✅ Muret (rayon 5-10km)
   ✅ Toulouse (rayon 15-20km)
   ✅ Communes listées
2. Google affichera annonce DANS ces zones
```

---

### ÉTAPE 5: Ajouter Méthodes de Paiement

**Temps: 5 min**

```
1. LSA > Paramètres > "Paiement"
2. Ajouter carte bancaire
   - Cardholder: "Nino Plomberie"
   - Adresse facturation: 11 Rue François Arago, 31600 Muret
3. Accepter conditions Google
4. Budget quotidien (recommandé: €50-100/jour)
5. SAUVEGARDER
```

---

### ÉTAPE 6: Configurer Services & Annonces

**Temps: 5 min**

```
1. LSA > "Services"
2. Pour chaque service (déjà ajouté):
   ✅ Fuite d'eau
   ✅ Débouchage
   ✅ Chauffe-eau
   ✅ Chauffage
   ✅ Robinetterie
   ✅ Rénovation salle de bain
   ✅ Plomberie neuve

3. Pour chaque:
   - Vérifier description
   - Activer "Afficher dans LSA"
   - Définir prix (OPTIONNEL)
   - Upload 1-3 photos
4. SAUVEGARDER
```

---

### ÉTAPE 7: Activer Garantie Google

**Temps: 5 min**

```
1. LSA > Paramètres > "Google Guarantee"
2. Accepter conditions
3. Vérifier:
   - [✓] Vous avez passé vérification d'identité
   - [✓] You have a valid payment method
   - [✓] Services added and approved
4. Cliquer "Activer Google Guarantee"
```

**Une fois activé:** Badge "Google Guaranteed" apparaît dans les annonces

## 🐛 Troubleshooting

### ❌ "Annonce pas affichée après 24h"
```
✓ Vérifier profil LSA est COMPLÈTEMENT rempli
✓ Vérifier services ajoutés et activés
✓ Vérifier Google Guarantee accepté
✓ Attendre 48-72h (parfois délai)
✓ Contacter support Google
```

### ❌ "Pas d'appels reçus"
```
✓ Vérifier zone d'intervention définie
✓ Vérifier "Accepter leads" activé
✓ Demander rétroaction Google (peut être rejet lead)
✓ Augmenter budget quotidien (€50 → €100)
```

### ❌ "Trop d'appels non qualifiés"
```
✓ Affiner zone d'intervention (enlever villes lointaines)
✓ Améliorer description (être spécifique)
✓ Utiliser "refuser lead" pour rejecter non-pertinents
✓ Baisser budget si nécessaire
```
